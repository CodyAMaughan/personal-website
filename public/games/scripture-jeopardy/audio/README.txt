Drop up to 4 Jeopardy theme variants here, named:

  jeopardy-1.mp3
  jeopardy-2.mp3
  jeopardy-3.mp3
  jeopardy-4.mp3

The game randomly picks one every time a clue is opened, but will never play
the same one twice in a row. Missing files are silently skipped (so 1, 2, 3,
or 4 files all work — just keep them numbered starting at 1).

Each track:
- starts (looped) when a clue is revealed
- stops when the answer is shown or the modal is closed

If no files are present, the game still works — only the built-in click/reveal
beeps will play.
